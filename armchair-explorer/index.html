About City Explorer - Neighborhoods Test

This version tests the neighborhood exploration feature.

How to Use

  1. Enter a city name and click OK
  2. Click the "Neighborhoods" button
  3. Wait for the neighborhood list to load
  4. Select a neighborhood from the dropdown
  5. Explore using the History, Food, and Character tabs
